Nhập từ Google Sheet

Cách 1 – Copy & dán (dễ nhất): trong Google Sheet, quét chọn các dòng cần nhập (có hoặc không kèm dòng tiêu đề), nhấn Ctrl+C rồi dán vào ô dưới đây. Các cột phải theo đúng thứ tự của File Excel mẫu.

Cách 2 – Dán link Google Sheet: sheet cần để chế độ "Bất kỳ ai có đường liên kết đều xem được". Trang sẽ đọc trang tính tương ứng với đường link (gid).

Tạo sheet đúng mẫu: bấm "⬇ File Excel mẫu", tải file lên Google Drive rồi mở bằng Google Sheets – có sẵn các cột đúng thứ tự.

Lưu trữ khi bấm "Lưu hồ sơ"

Mỗi lần bấm "Lưu hồ sơ", trang tự động tải file Word (hồ sơ này) và file Excel (tất cả hồ sơ đã lưu).

Cách lấy link Google Drive (làm 1 lần)
  1. Vào script.google.com → Dự án mới, xóa mã cũ, dán đoạn mã bên dưới.
  2. Bấm Triển khai → Tùy chọn triển khai mới → Ứng dụng web: "Thực thi với tư cách" = Tôi; "Ai có quyền truy cập" = Bất kỳ ai.
  3. Cấp quyền truy cập Drive khi được hỏi, rồi sao chép URL ứng dụng web dán vào ô trên.

File được lưu trong thư mục "Báo cáo trường hợp bệnh" trên Drive của bạn. Chức năng Drive chỉ chạy khi mở trực tiếp file HTML này trên máy, không chạy trong claude.ai.
